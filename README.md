# West Lane · Lista de Tarefas

Painel de tarefas para os sócios da West Lane. É um único arquivo (`index.html`) — basta abrir no navegador.

## Funções
- Adicionar tarefas rapidamente (digite e aperte Enter)
- Marcar como concluída com um clique (com opção de desfazer)
- Editar clicando na tarefa: título, notas, responsável, prioridade, categoria, prazo e subtarefas
- Responsável: cada sócio ou ambos (nomes configuráveis no menu ⋯)
- Filtros: pendentes, hoje, atrasadas, alta prioridade, concluídas, todas
- Busca, filtro por responsável e categoria, ordenação (manual, prazo, prioridade, recentes)
- Arrastar para reordenar, duplicar, excluir (com desfazer)
- Resumo com contadores e barra de progresso
- Tema claro/escuro, funciona no celular
- Backup: exportar/importar em `.json`

Atalhos: `N` nova tarefa · `/` buscar.

Os dados ficam salvos no navegador (localStorage) de quem está usando.
